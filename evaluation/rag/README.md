# RAG 检索质量评测

`retrieval_cases.json` 保存可以提交 Git 的通用服装知识问题，不包含真实用户
消息或个人数据。每条问题声明期望命中的 `knowledge_id`、允许命中的稳定
`section_id`，以及最大结果排名。

当前问题集覆盖：

- 面料
- 场景
- 天气
- 衣物护理

## 运行方式

在项目根目录执行：

```powershell
python -m scripts.evaluate_knowledge_retrieval
```

评测脚本只读取当前 Chroma 集合，不执行知识入库或修改知识文件。它会逐条输出
是否通过、预期来源的排名，以及实际命中的 `fragment_id` 和来源路径。只要存在
未通过的问题，进程就会返回非零退出码，便于未来接入 CI 或知识发布检查。

运行正式评测会初始化项目配置、Embedding 和 Chroma，因此应先确认本机已经缓存
所需模型，并按照项目权限规则获得真实运行许可。

## 判定规则

问题只有在 `max_rank` 范围内同时满足以下条件才通过：

1. 命中预期 `knowledge_id`；
2. 命中该问题允许的至少一个 `section_id`。

只命中正确文档但章节无关时不会通过。这样可以避免把“有返回结果”误认为“召回
内容相关”。

允许章节应通过人工阅读正文确定。核心结论、决策步骤、适用示例或证据摘要只要能
直接支持当前问题，都可以列入；不得为了提高通过率而加入只有标题相关、正文无关的
章节。
