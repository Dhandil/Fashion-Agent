# Fashion Agent Requirements


## 用户需求

### 用户故事1

作为用户，

我希望告诉 Agent 我的购买需求，

Agent 可以理解我的需求。


例如：

"我想买一件夏天通勤穿的短袖，
预算200以内"


Agent应该识别：

- 商品类别
- 使用场景
- 预算
- 风格


---

### 用户故事2

作为用户，

我希望 Agent 可以推荐合适商品。


输入：

身高
体重
偏好


输出：

商品推荐。


---

### 用户故事3

作为用户，

我希望 Agent 记住我的偏好。


例如：

我喜欢：

- 宽松版型
- 黑白灰颜色


以后推荐自动考虑。


---

# 第一版本范围(MVP)

包含：

1. 基础聊天

2. 服装知识RAG

3. 商品搜索Tool

4. 简单用户Memory


暂不包含：

- 支付
- 下单
- 真实电商接口
- 图片试穿
